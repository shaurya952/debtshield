# Pricing Experiments

_Hypotheses to test, not published prices. Numbers below are **placeholders to
validate**, clearly marked; do not quote them as real pricing._

## Principles
- Price the **service and outcome** (deployment, training, reporting), not
  personal data.
- Keep it affordable for mission-driven buyers (nonprofits, community programs).
- Simple, transparent, no per-individual-data pricing.

## Structures to test
1. **Flat pilot fee** — one price for a time-boxed pilot (setup + training +
   end-of-pilot aggregate report). Easiest first sale.
2. **Annual program license** — tiered by organization size or participant band,
   including data updates + support.
3. **Per-seat / per-participant** — only if it can be counted without exposing
   individuals; risk: feels like surveillance. Test cautiously.

## Placeholder ranges (TO VALIDATE — not real prices)
| Structure | Placeholder | What to learn |
|---|---|---|
| Pilot fee | e.g. low-four-figures | Will a program pay anything up front? |
| Annual license (small) | e.g. four-figures/yr | Does size-based tiering feel fair? |
| Nonprofit discount | e.g. 40–60% off | Needed to reach mission buyers? |

## How to test
- Offer 2–3 named options in pilot proposals; track which is chosen and where
  buyers balk (see `SALES_PIPELINE_SCHEMA.md`).
- Van Westendorp-style questions in discovery ("too cheap / too expensive").
- Never fabricate "others pay X"; cite only real signals.

## Kill/adjust criteria
- If no mission buyer will pay a pilot fee after N qualified conversations,
  revisit value (maybe grants/sponsorship instead of direct fees).
